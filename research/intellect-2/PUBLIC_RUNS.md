# INTELLECT-2 public evidence

The primary source is Prime Intellect’s [INTELLECT-2 technical report](https://arxiv.org/abs/2505.07291) and [official release post](https://www.primeintellect.ai/blog/intellect-2-release). Its source code is [prime-rl](https://github.com/PrimeIntellect-ai/prime-rl); supporting sources include [TOPLOC](https://github.com/PrimeIntellect-ai/toploc) and the [Prime protocol](https://github.com/PrimeIntellect-ai/protocol). The official post and paper describe SHARDCAST, but do not link a public source repository. A single check of the guessed `PrimeIntellect-ai/shardcast` GitHub URL returned 404, so it was not cloned.

The report describes a 32B QwQ-based reasoning model trained with globally distributed asynchronous RL. It reports two principal experiments, TARGET-SHORT and TARGET-LONG. Figure 12 shows 10-step-smoothed task-reward and length-penalty curves: task rewards rose, while length penalties fell more slowly. The authors explicitly say the length-following objective did not converge within the run window. This is paper-figure evidence, not an independently checked raw run history.

The report gives training and inference timing, policy broadcast, throughput, and validation details, but the observed public materials do not include a node-by-node contributor ledger or raw rollout/metric exports. It describes a contribution ledger in the protocol design; that architectural description does not establish actual per-node contribution for the INTELLECT-2 run. No public dashboard or W&B run-history link is present in the report or release post. The official protocol README links an `intellect-2` app route, which returned HTTP 404 in the current no-login capture.

The `prime-rl` clone is a full-history snapshot of evolving `main` (captured October 29, 2026). Its first stable `v0.1` tag is dated July 3, 2025, after the May report. No report or source link pins the deployed training SHA, so neither current `main` nor the later release is attributed to the run. A May 7 code change titled “Change default wandb project” edits a 1.5B debug configuration only; it does not identify an INTELLECT-2 W&B project or run.

The archive stores the paper/release pages, browser captures, and Hugging Face model/dataset metadata. It excludes model weights and dataset rows or files. See [SOURCE.json](SOURCE.json) for source pins and [INVENTORY.md](INVENTORY.md) for paths. The ignored snapshot is stored at `data/extended_20261029/public_sources/`.
